# Screenshot

Letakan file screenshot hasil capture emulator di folder ini dengan nama:

- `home.png` — Home Screen dengan daftar game
- `search.png` — Home Screen saat mengetik di search bar
- `detail.png` — Game Detail Screen
- `empty-state.png` — hasil search yang tidak ditemukan
- `error-state.png` — state error (tanpa koneksi) + tombol Coba Lagi

Nama file harus sama persis dengan yang dirujuk di README.md.
